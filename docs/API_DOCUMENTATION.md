# ShopBridge Inventory REST API Documentation

The **ShopBridge API** is a NestJS-based REST service that handles CRUD operations for inventory management.

- **Base URL (Local Development)**: `http://localhost:3333/api`
- **Global API Prefix**: `/api`
- **Content-Type**: `application/json`

---

## Data Models

### `InventoryItemDataModel`

```typescript
export interface InventoryItemDataModel {
    id?: number; // Unique numerical ID (generated by backend)
    name: string; // Item name (Must be unique across inventory)
    description: string; // Detailed item description
    price: number; // Item price in currency units
}
```

---

## API Endpoints

### 1. Get Whole Inventory List

Retrieve all items currently stored in the inventory.

- **HTTP Method**: `GET`
- **Endpoint**: `/api/inventory/list`
- **Response**: `200 OK`
- **Response Body**: Array of `InventoryItemDataModel`

#### Sample Response:

```json
[
    {
        "id": 1001,
        "name": "Item1 - Monitor",
        "description": "Dell FHD Monitor",
        "price": 6000
    },
    {
        "id": 1002,
        "name": "Item2 - Logi MX mouse 3",
        "description": "Logitech Master series ergonomic mouse 3",
        "price": 8000
    }
]
```

---

### 2. Get Single Inventory Item

Retrieve details for a specific item using its numerical ID.

- **HTTP Method**: `GET`
- **Endpoint**: `/api/inventory/get/:id`
- **URL Parameters**:
    - `id` _(number, required)_ - Item ID
- **Response Codes**:
    - `200 OK` - Item found
    - `404 Not Found` - Item with given ID does not exist

#### Sample Request:

`GET /api/inventory/get/1001`

#### Sample Response (`200 OK`):

```json
{
    "id": 1001,
    "name": "Item1 - Monitor",
    "description": "Dell FHD Monitor",
    "price": 6000
}
```

#### Sample Response (`404 Not Found`):

```json
{
    "statusCode": 404,
    "message": "Item not found.",
    "error": "Not Found"
}
```

---

### 3. Add Item to Inventory

Create a new inventory record. The system validates that the item `name` is unique and auto-generates a new incremental ID.

- **HTTP Method**: `POST`
- **Endpoint**: `/api/inventory/add`
- **Request Body**: `InventoryItemDataModel` (without `id`)
- **Response Codes**:
    - `201 Created` - Item created successfully
    - `422 Unprocessable Entity` - Item name already exists in inventory

#### Sample Request Payload:

```json
{
    "name": "Keychron K2 Keyboard",
    "description": "Wireless mechanical keyboard with RGB backlight",
    "price": 7500
}
```

#### Sample Response (`201 Created`):

```json
{
    "id": 1003,
    "name": "Keychron K2 Keyboard",
    "description": "Wireless mechanical keyboard with RGB backlight",
    "price": 7500
}
```

#### Sample Error Response (`422 Unprocessable Entity`):

```json
{
    "statusCode": 422,
    "message": "Item name already exists.",
    "error": "Unprocessable Entity"
}
```

---

### 4. Update Inventory Item

Update existing details of an item by ID. Enforces unique name validation against other inventory items.

- **HTTP Method**: `PUT`
- **Endpoint**: `/api/inventory/update/:id`
- **URL Parameters**:
    - `id` _(number, required)_ - Item ID
- **Request Body**: `InventoryItemDataModel`
- **Response Codes**:
    - `200 OK` - Item updated successfully
    - `404 Not Found` - Item ID not found
    - `422 Unprocessable Entity` - Updated name conflicts with another existing item

#### Sample Request:

`PUT /api/inventory/update/1001`

#### Sample Request Payload:

```json
{
    "name": "Dell UltraSharp 27 Monitor",
    "description": "Dell 4K IPS Monitor with USB-C Hub",
    "price": 32000
}
```

#### Sample Response (`200 OK`):

```json
{
    "id": 1001,
    "name": "Dell UltraSharp 27 Monitor",
    "description": "Dell 4K IPS Monitor with USB-C Hub",
    "price": 32000
}
```

---

### 5. Delete Inventory Item

Remove an item from inventory by ID.

- **HTTP Method**: `DELETE`
- **Endpoint**: `/api/inventory/del/:id`
- **URL Parameters**:
    - `id` _(number, required)_ - Item ID
- **Response Codes**:
    - `200 OK` - Item deleted successfully
    - `404 Not Found` - Item ID not found

#### Sample Request:

`DELETE /api/inventory/del/1002`

#### Sample Response (`200 OK`):

_(Empty Response Body)_
